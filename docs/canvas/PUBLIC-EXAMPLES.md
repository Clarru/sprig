# Public examples

The catalogue contains three fictional product conversations: festival meeting points, a car-wrapping website funnel, and email onboarding. Each path contains fourteen turns, with two choices that materially affect the result. Later turns cover consequences, recovery and corrections instead of stopping after an initial sketch.

The examples share the real editor, operations and companion, but use authored transactions and make no microphone or AI calls. They are separate from the owner's personal recording material. The default is the festival feature discussion.

`scenarios.ts` supplies the initial decisions and branches; `scenario-continuations.ts` develops each into a reviewable workflow. Keep branch-specific consequences intact: an estimate is not a reviewed quote, delivery is not authentication, and an optional location permission is not required to open an invitation.

Back, Restart and editable copies must work for every path. Validate every prefix as a versioned board, check the semantic connections, and exercise the branches in a browser before publishing.
